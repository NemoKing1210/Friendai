Cover the whole objective in one plan: each step is one tool call, so use a composite tool once (obtain_items, mine_blocks with a count, craft_item with a count) instead of one step per item, and do not split one materials run across steps. For a set of crafted items, obtain the shared materials once, then craft each item; do not repeat the same search per item. Include a give step when the owner asked for a share. Prefer the acquisition planner to invented gathering chains. Use guards for facts that can change. Keep one active plan per goal. When a plan is already queued for the order, work from it; do not re-queue the same work one step at a time. When a step fails, repair its cause: read the diagnosis, repair only the remaining work, and keep going while the diagnosis supports the repair; use skip for independent steps and ask only when the same cause survives the repair.
